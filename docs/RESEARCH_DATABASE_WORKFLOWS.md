# Research database workflows

Use `examples/workflows/research-database-search-dry-run.yaml` as a starting point. Real paid database runs require visible browser access and user/institution authorization.

Safe sequence:

1. Launch `research-default` profile.
2. Let the user confirm access or institutional login.
3. Discover capabilities.
4. Compile a dry-run workflow.
5. Execute only official visible UI operations and stop on blockers.
